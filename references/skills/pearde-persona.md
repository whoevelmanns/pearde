Read @references/parts/personas.md — the signals table that picks one, the
three scopes, **What never switches it**, and why it is session state in
`PEARDE_AS` rather than a file on the board. The roster is
@references/personas/INDEX.md; the scope is `@@personas`.

A question aimed at one problem does not need a switch — that is
`pearde-persona-ask`, which changes nothing. This skill is for the switch
itself.

Say the active persona and *why* it is the right reading for what is in front
of you. "engineer, because nothing here turns on a design call" is an answer;
naming the id alone is not.
