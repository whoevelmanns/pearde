## PRD board (prd)

This repo has a PRD board. On "prd", "work the board", "run the prds", or
"prd status": read `<skill>/README.md` and follow it exactly. It defines the
board under `prds/`, the PRD states, the loop, the analyst and implementer
briefs, and the templates beside it.

Write everything — PRDs, specs, reports — per `LANGUAGE.md` in that folder:
short, on the point, precise, no legacy. Ask per `DRILL.md`: one round, the
whole frontier, each question with your recommended answer.

Not wired up yet? `INSTALL.md` in that folder says what installed means.
No parallel workers? Run the single-agent mode it describes.

Handles: `status`, `once`, `add <title>`, `drill <prd>`, `retry <prd>`,
`run <prd>`, `workers=N`, `pipeline=N`.
