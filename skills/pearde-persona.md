Read @references/parts/personas.md. The roster is
@references/personas/INDEX.md; the scope is `@@personas`.

- **Cheap to call, expensive to become.** A switch re-aims every round that
  follows. A question aimed at one problem does not need one — that is
  `pearde-persona-ask`.
- **The user naming one is not a question.** Wear it.
- **A candidate that differs from the active persona and governs the round:
  ask once**, recommend the candidate, wear the answer. Never switch
  silently, and never switch because a single task looked like someone else's
  field.
- **It is session state and nothing else.** No file records it. The round's
  `· as <id>` line is the only place it appears, per @references/parts/progress.md.
- **What never switches it** is its own section in @references/parts/personas.md
  — read it before deciding a switch is owed. A dispatched worker's persona
  comes from its own job and moves nothing.

Say the active persona and *why* it is the right reading for what is in front
of you. "engineer, because nothing here turns on a design call" is an answer;
naming the id alone is not.
